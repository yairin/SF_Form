# תוכנית סגירת פערים — טפסים עירוניים (Native-first, PSS)

מסמך זה מפרט את התוכנית להעלאת מחולל הטפסים מרמת "טופס פשוט" לרמת "טופס בקשה
עירוני" מלא (בהשראת ה-smartforms של רשויות בישראל). כל שלב נפרס דרך ה-CI ונבדק
מקצה-לקצה לפני המעבר לשלב הבא.

## עקרונות
- **Native-first**: LWC + Apex + Experience Cloud + PSS; שקילת OmniStudio לתהליכים כבדים.
- **ולידציה בשרת תמיד** (לא לסמוך על צד לקוח); הקשחת Guest.
- כל תשובה נשמרת גם ל-`Form_Answer__c` לצורך דיווח; שמירת `Response_Data__c` המקורי.
- פריסה מדורגת: כל תת-שלב = commit + bump ל-`ops/deploy.trigger` + ריצת CI ירוקה.

---

## גל 1 — פאריטי "בקשה בסיסית"

### שלב א׳ — ולידציה בשרת + סוגי שדה חדשים  ← מבוצע כעת
- `FormValidationService` (Apex): אימות מול סכימת התבנית — שדות חובה, פורמט
  אימייל/טלפון/מספר/תאריך, ו**ביקורת ספרת ביקורת לתעודת זהות ישראלית**.
- שילוב ב-`FormResponseController.submitResponse` — חסימת הגשה לא תקינה עם הודעות בעברית.
- סוגי שדה חדשים בבונה ובמרנדר: `idNumber` (ת"ז), `currency` (סכום ₪).
- ולידציית ת"ז גם בצד לקוח (UX) — השרת הוא הסמכות.
- בדיקות Apex: הגשה תקינה, חסימת חובה, ת"ז תקינה/שגויה.

### שלב ב׳ — העלאת מסמכים
- סוג שדה `file` בבונה; רכיב העלאה במרנדר → `ContentVersion` המקושר ל-`Form_Response__c`.
- הרשאת Guest ל-`ContentVersion` (create) + הקשחה (סוגי קובץ/גודל).
- קישור התמונות/מסמכים ברשומה למנהל.

### שלב ג׳ — אשף רב-שלבי + לוגיקה מותנית
- סכימה מורחבת: קיבוץ שדות ל-`sections`/`steps` + כללי הצגה (`visibleWhen`).
- מרנדר Wizard עם התקדמות; ולידציה מצטברת פר-שלב.
- שדות מבניים: כתובת (עיר/רחוב/מס'/דירה/מיקוד), שעה.

### שלב ד׳ — אישור והתראות
- מסך אישור + מספר סימוכין (קיים) → הוספת **אימייל/SMS** (Flow) ו-**PDF סיכום**.
- התראות פנימיות בשינוי סטטוס / חריגת SLA.

## גל 2 — סקרים ותוצאות
- סוגי שאלה: דירוג (1–5), NPS, מטריצה/רשת, בחירה יחידה/מרובה.
- **טאב "תוצאות"**: רשימת טפסים → טבלת תוצאות מלאה + גרפים אוטומטיים לפי סוג שדה
  + סיכום מילולי (היברידי: חוקים + Einstein GenAI אם מופעל).
- עמידה בהיקף ציבורי גדול (בדיקת מגבלות Guest, bulk-safe).

---

## גל 3 — סטטוטורי מלא
- **תשלום אגרה** (סליקה) לטפסים כגון הנפקת תעודה.
- **חתימה דיגיטלית** (signature pad) + הצהרות/תצהיר.
- **מעקב סטטוס לפונה** ("איפה הבקשה שלי") — לפי מס' סימוכין + ת"ז.
- **נגישות ת"י 5568 / WCAG 2.0 AA** — ביקורת ותיקון.
- CAPTCHA/אנטי-ספאם + הגבלת קצב; שמירת טיוטות (Save & Resume).

---

## גל 4 — מורכב / אינטגרטיבי
- **OmniStudio OmniScript + DataRaptor + FlexCards** לתהליכים כבדים (מודל היברידי).
- **Flow Orchestrator / Approvals** לתהליך פנימי רב-שלבי.
- **מפה / GIS** לתלונות מבוססות-מיקום + צילום.
- **רב-לשוני** (עברית/ערבית/רוסית/אנגלית) — Translation Workbench / Custom Labels.
- ניהול **גרסאות תבנית** ואודיט הגשות.
