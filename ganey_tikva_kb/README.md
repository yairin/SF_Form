# פריטי מידע – אתר עיריית גני תקווה

כלים להפקת קובץ אקסל של פריטי מידע מתוך https://www.ganeytikva.org.il

## החלטות שאושרו מול המשתמש
- מקור: האתר הראשי בלבד, ללא החרגות. קבצים מצורפים (PDF/Word) – כקישור בלבד.
- פירוק דפים לכמה פריטים ככל שרלוונטי. מטרה: מענה ברור לתושב ולנציג מוקד טלפוני.
- קוד פריט: מספר סודר (1, 2, 3...).
- טקסט: עשיר בתוך תא האקסל (כותרות, הדגשות, תבליטים); תמונות כקישור לתמונה המקורית.
- עמודות עזר: קטגוריה, כתובת מקור, קבצים מצורפים, תאריך עדכון.
- התוכן עובר עריכה (לא העתקה כלשונו); לכלול פרטי קשר כפי שמופיעים באתר.
- לפני מעבר על כל האתר: 8 דוגמאות לאישור.

## שימוש
1. `python3 -I crawl.py raw/` – סריקת האתר (דורש גישת רשת ל-ganeytikva.org.il).
2. עריכה ופירוק לפריטים ל-`items.json` (מבנה מתועד בראש build_xlsx.py).
3. `python3 -I build_xlsx.py items.json out.xlsx`
